# Hey Chat

Your own Instagram comment-to-DM automations, without a ManyChat subscription.

Choose a reel and a keyword. When someone comments that keyword, send them a DM with your link. You can also reply under their comment and send a follow-up if they message back.

## Get started with your AI assistant

Paste this into a coding assistant that can work with files and run commands on your computer:

```text
Help me install Hey Chat: https://github.com/trishalim/hey-chat

Read AGENTS.md, then create my own PRIVATE repository from this source.
GitHub forks of public repos cannot be private, so use an independent
private copy and keep the original as upstream for updates. Verify my
repo is private before pushing my changes or deploying. Ask me the setup questions
one or two at a time, in plain language, and do the technical work for me.
Help me choose between trying it locally and deploying it online.
Guide me through connecting my Instagram account. Ask before creating
anything paid, keep my credentials private, and verify a real
comment-to-DM delivery before saying it works.
```

Your assistant will walk you through setup, hosting, and connecting Instagram. You don't need to read the technical instructions yourself.

## What you'll need

- An Instagram **Creator or Business** account.
- Your own **Meta developer app**. Your assistant can help you set it up; you'll still need to log in and complete authorization steps.
- Hosting that stays online if you want replies running all day. The code is free; hosting or database services may cost money.

Each installation is for one Instagram account. This isn't a shared service where everyone signs in with Instagram.

## Once it's set up

Open your installation's `/admin` page and log in with your generated password. Paste a reel link, choose a keyword, write your message, and turn the automation on. Check **Activity** to see delivery results.

Your deployment URL can be visited by other people, but the admin requires your password. A private GitHub repo does not make the website private. Keep your generated password in a password manager and never commit credentials.

Your assistant will create a **private copy** of this project for deployment. GitHub's **Fork** button creates a public fork of this public repository; use the prompt above for a private installation instead.

The app currently displays the name **Little Chat**—that's this project.

For manual setup or technical details, see [AGENTS.md](AGENTS.md).
